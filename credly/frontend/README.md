# AI-Powered Trading Terminal 🚀
A real-time stock monitoring dashboard with an integrated **Gemini AI Strategy Advisor**. This app fetches live market data and provides AI-driven insights into portfolio performance.

## ✨ Features
* **Live Market Stream:** Real-time price tracking and automated refreshes.
* **AI Strategy Advisor:** Quantitative analysis of stock momentum and risk.
* **Portfolio Management:** Track assets, cash balance and performance.
* **Interactive Charts:** Visual price action history using Recharts.

## 🛠️ Tech Stack
* **Frontend:** React, Tailwind CSS, Lucide React, Framer Motion.
* **Backend:** Netlify (Serverless).
* **AI:** Google Gemini.
* **Data:** Finnhub Stock API.
